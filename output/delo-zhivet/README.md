# Delo Zhivet Guix Packaging

Этот репозиторий содержит рецепты Guix пакетов для проекта "Дело живёт".

## Ограничения и особенности сборки

Guix требует полной воспроизводимости и не допускает сетевых запросов во время сборки в build container.
В связи с тем, что полноценная сборка `backend` и `bot` (Java/Spring Boot/Gradle) требует упаковки порядка 150+ Maven-зависимостей как отдельных Guix пакетов, а `frontend` (Node/Vite) требует упаковки NPM зависимостей, в рамках текущего решения применяются `*-bin` пакеты (pre-built release artifacts).

**Это честное временное deployment-решение. Пакеты устанавливают уже скомпилированные артефакты, собранные вне Guix.**

## Как собрать релизные артефакты локально

Перед тем как эти пакеты можно будет установить, необходимо подготовить релизные артефакты и загрузить их в публичное хранилище (например, Git release assets или S3).

### Backend
1. Перейдите в директорию бэкенда:
   ```bash
   cd references/backend
   ```
2. Соберите jar:
   ```bash
   ./gradlew bootJar
   ```
3. Загрузите полученный артефакт (например, `build/libs/backend-1.0.0.jar`) на ваш сервер релизов:
   ```
   https://releases.example.com/backend-1.0.0.jar
   ```

### Bot
1. Перейдите в директорию бота:
   ```bash
   cd references/bot
   ```
2. Соберите jar:
   ```bash
   ./gradlew bootJar
   ```
3. Загрузите полученный артефакт (например, `build/libs/bot-1.0.0.jar`) на ваш сервер релизов:
   ```
   https://releases.example.com/bot-1.0.0.jar
   ```

### Frontend
1. Перейдите в директорию фронтенда:
   ```bash
   cd references/frontend
   ```
2. Установите зависимости и соберите статику:
   ```bash
   npm ci
   npm run build
   ```
3. Упакуйте директорию `dist/` в архив:
   ```bash
   tar -czvf frontend-1.0.0.tar.gz -C dist .
   ```
4. Загрузите архив на ваш сервер релизов:
   ```
   https://releases.example.com/frontend-1.0.0.tar.gz
   ```

## Обновление хешей в Guix пакетах

После загрузки релизных файлов вам нужно вычислить их sha256 хеши в формате base32 и обновить их в файле `packages.scm`.

Для получения хеша используйте команду `guix hash`:

```bash
guix hash frontend-1.0.0.tar.gz
```

Полученный хеш вставьте в поле `(sha256 (base32 "..."))` соответствующего пакета в `packages.scm`. Не забудьте также обновить URL скачивания (`uri`).
