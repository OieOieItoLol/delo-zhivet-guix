GNU Guix Рецепты

В этом документе представлены учебные пособия и подробные примеры для GNU Guix, инструмента для функционального управления пакетами, написанного для системы GNU. Пожалуйста, see справочное руководство GNU Guix для получения подробной информации о системе, ее API и связанных с ней идеях.

Это руководство также доступно на английском (see GNU Guix Cookbook), (упрощённом) китайском языке (see GNU Guix 烹饪书), французском (see Livre de recettes de GNU Guix), немецком (see GNU-Guix-Kochbuch), корейском (see GNU Guix 쿡북), испанском (see Libro de recetas de GNU Guix), итальянском (see Ricettario di GNU Guix), бразильский португальский (see Livro de receitas do GNU Guix), словацкий (see Receptár GNU Guix), шведский (see Kokbok för GNU Guix) и тами́льском (see GNU Guix கையேடு). Если вы хотите перевести этот документ на свой родной язык, присоединяйтесь к Weblate (see Перевод Guix на другие языки in Руководство по GNU Guix).
